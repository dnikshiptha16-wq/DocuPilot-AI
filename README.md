# DocuPilot AI — Business Documents into Actionable Information

DocuPilot AI is a Streamlit application designed to process business documents (.pdf and .docx) and extract structured insights, action items, and key metrics using Google Gemini AI.

## Technical Stack & Requirements

- **Python Version:** 3.13.x
- **Virtual Environment:** `.venv`
- **SDK:** `google-genai`
- **Model:** `gemini-3.8-flash`

## Local Setup Instructions

1. Activate your virtual environment (`.venv`):
   - **Windows:** `.venv\Scripts\activate`
   - **macOS/Linux:** `source .venv/bin/activate`

2. Install dependencies:
   ```bash
   pip install -r requirements.txt
